# Plugin-Flex-o-NX
Plugin para o NX 9.0 utilizado para ver o erro geométrico causado pela flexão da ferramenta no processo de usinagem
o programa é pensado para fazer as verificações propostas em uma usinagem de 2,5 eixos, sendo consideradas análises para
futuramente faze-lo analisar 3 eixos (com certa correlação)
